# Skill: Analisar Candidato (TalentBridge)

Esta skill para o Claude Code automatiza a análise de currículos e perfis técnicos, calculando um "Score de Match" e gerando um plano de ação (feedback) para o candidato baseado em Hard Skills, Soft Skills e Geolocalização.

## Como utilizar noutro projeto
Para utilizares esta skill no teu próprio agente, copia a pasta `analisar-candidato` para dentro do diretório `.claude/skills/` do teu repositório e reinicia o Claude Code.

# TalentBridge

## Contexto
O TalentBridge atua como uma plataforma de Matchmaking profissional de mão dupla para públicos B2C e B2B[cite: 33]. O objetivo é eliminar o atrito no processo de recrutamento através de dados precisos (Hard Skills, Soft Skills e geolocalização) e avaliações psicológicas embasadas[cite: 33].

## Convenções Técnicas
- A stack principal é baseada no ecossistema JavaScript: backend em Node.js e frontend em React com Next.js[cite: 34].
- Priorize funções assíncronas (`async/await`) e utilize sempre `===` nas comparações.

## Comandos Úteis
- Iniciar o servidor de desenvolvimento: `npm run dev`
